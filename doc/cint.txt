1. INTRODUCTION                          *cint-introduction*

Renders annotations from analysis-engine as background tints and gutter signs,
coloring code by intent (Logging, Error Handling, ...) instead of by syntax.

The renderer is socket-only. It starts (or attaches to) a per-project analysis
daemon, sends buffer text and versions over a Unix socket, and renders the
annotations the daemon publishes. There is no artifact or offline mode.

The daemon publishes the analyzed version and content hash with each result. The
client ignores tags for outdated buffer versions and keeps the previous marks
visible until the matching version arrives.

A scaffold with more than one intent never receives a single tag color. Color
handlers are skipped for it, while IGNORE/CONCEAL still apply, and the inner
spans keep their own styling.

2. SETUP                                            *cint-setup*

Install the plugin, then call setup() (optional; defaults are used otherwise): >

  require("cint").setup({
    root_markers = { ".git" },
    auto_render = true,
    live_lsp = true,
    scope = "project",
    languages = {
      { language = "kotlin", filetypes = { "kotlin" }, extensions = { ".kt", ".kts" } },
      {
        language = "javascript",
        filetypes = { "javascript", "javascriptreact" },
        extensions = { ".js", ".jsx", ".mjs", ".cjs" },
      },
      { language = "typescript", filetypes = { "typescript" }, extensions = { ".ts", ".mts", ".cts" } },
      { language = "vue", filetypes = { "vue" }, extensions = { ".vue" } },
      { language = "csharp", filetypes = { "cs", "csharp" }, extensions = { ".cs" } },
    },
    resolve = {
      precedence = { "SHOW", "HIGHLIGHT", "IGNORE", "CONCEAL" },
      default = "SHOW",
    },
    rules = {
      CONCEAL = { conceal = { lines = true } },
      SHOW = { highlight = true },
      IGNORE = { ignore = true },
    },
    tags = {
      LOGGING = { meaning = "CONCEAL", bg = "#1f2d1f", priority = 10 },
      ERROR_HANDLING = { meaning = "SHOW", bg = "#2d1f1f", priority = 50 },
      UNTAGGED = { meaning = "SHOW" },
    },
  })
<

Dev install with a plugin manager (rtp path): >

  { dir = "~/repos/code-intent/nvim-renderer", config = function()
      require("cint").setup({ auto_render = true })
    end }
<

3. COMMANDS                                      *cint-commands*

:CintRender                                *:CintRender*
    Render intent tags for the current buffer.

:CintClear                                 *:CintClear*
    Remove decorations from the current buffer.

:CintToggle                                *:CintToggle*
    Toggle decorations on the current buffer.

:CintRefresh                               *:CintRefresh*
    Reconnect and re-analyze the current buffer.

:CintInfo                                  *:CintInfo*
    Show current configuration and active profile.

:CintProfile                               *:CintProfile*
    With no argument: pick a profile. With a name: set it for the current
    buffer, or globally if the buffer is not rendered. With !: set the global
    profile and clear buffer overrides.

:CintProfileEdit [name]                    *:CintProfileEdit*
    Open the profile file (project or global per `scope`) in a Lua buffer. Save
    to reload.

:CintProfileReload                         *:CintProfileReload*
    Reload profiles and re-render.

:CintShard                                 *:CintShard*
    With no argument: pick a shard to apply now. With a name: append it to the
    buffer shard history. With !: append it globally.

:CintShardUndo                             *:CintShardUndo*
    Pop the last applied shard.

:CintShardReset                            *:CintShardReset*
    Clear the shard history.

:CintShardHistory                          *:CintShardHistory*
    Show applied shard history, oldest to newest.

:CintAnalyze                               *:CintAnalyze*
    Request an immediate live re-analysis.

:CintSuggest                               *:CintSuggest*
    Request an AI expression-discovery pass for the current buffer.
    Notifies `requesting AI suggestions` on start and reports when the pass
    finds no new candidates. A pass that adds AI candidates does not repeat the
    arrival notification from the candidate publish. A repeat suggest reuses the
    current analysis when the live document and published tags match the buffer
    version, so existing AI badges are not cleared and re-added. A busy server
    reports `AI suggestion pass already running`; disabled or otherwise
    unaccepted passes are not reported as no-result. Gated when the daemon is
    below protocol 3, its suggestions descriptor is missing, or suggestions are
    disabled in `.cint/suggestions.yml`.

:CintReview                                *:CintReview*
    Toggle buffer-local candidate review mode.

:CintReviewAccept [intent]                 *:CintReviewAccept*
    Accept the candidate under the cursor, optionally matching an intent.

:CintReviewDeny                            *:CintReviewDeny*
    Reject every alternative in the candidate group under the cursor.

Candidates render non-destructively outside review mode. Deterministic
candidates use a muted `?` sign and the dotted `CintCandidate` undercurl. AI
candidates (source starting with `ai:`) use a purple bold `AI` sign, the purple
`CintAiCandidate` undercurl, and one ` AI` badge at end of line per affected
line. The status count reads `CodeIntent: N unsure`, or
`CodeIntent: N unsure (M AI)` when AI candidates are present. When a publish
increases the AI candidate count the renderer notifies
`cint: AI added N candidate(s); :CintReview to inspect` once; republishes at the
same count do not notify again. Review mode keeps the existing
`CintCandidateReview` styling and evidence line.

:CintHover                                 *:CintHover*
    Show the distinct intents of the innermost published span under the cursor
    in a non-focusable floating window next to the caret. The reserved
    UNTAGGED marker is omitted, and UNTAGGED-only spans are ignored when
    choosing the innermost span. Intents are combined only when span bounds
    coincide; when multiple non-coincident spans share the smallest size, the
    earliest annotation in annotation order wins. A larger function or block
    scaffold does not contribute its intents when a nested span is under the
    caret. Each intent uses its tag color, with the
    fallback palette for unconfigured intents. The window closes on cursor
    movement, buffer/window leave, text change, window scroll, and resize. Also
    available as <Plug>(CintHover).

:CintLiveTags                              *:CintLiveTags*
    Open a scratch buffer showing the server's live tags for this buffer,
    including versions, profile, shards, and annotations.

:CintServerStatus                          *:CintServerStatus*
    Show live server connection status.

:CintServerDisconnect                      *:CintServerDisconnect*
    Disconnect from the live server. The daemon keeps running and is reused.

:CintServerStop                            *:CintServerStop*
    Stop the live daemon for the current project root. Use after changing
    engine config or rebuilding the server binary.

:CintServerRestart                         *:CintServerRestart*
    Stop the live daemon and spawn a fresh one for the current project root.

4. CONFIGURATION                            *cint-configuration*

`root_markers`    (table)   default: { ".git" }
    Markers used to locate the project root.

`root`            (string)  default: nil
    Explicit project root override (skips discovery).

`languages`       (table)   default: kotlin/javascript/typescript/vue/csharp
    Map Neovim filetypes and path extensions to engine language ids. Filetypes
    are checked first; extensions are the fallback.

`auto_render`     (boolean) default: false
    Render automatically on `BufReadPost`.

`live_lsp`        (boolean) default: true
    Let the daemon use its LSP oracle. `false` starts it with `--no-lsp`.

`scope`           (string)  default: "project"
    `"project"` loads `<root>/.cint/profiles.lua` and allows buffer-local
    profile/shard history. `"global"` loads
    `stdpath("config")/cint/profiles.lua`, ignores project
    files, and forces global profile/shard selection.

`server_cmd`      (table|string) default: { "cint-server" }
    Daemon command. A string is split on whitespace. The plugin appends the
    socket, root, and `--no-lsp` arguments.

`server_log`      (string|false) default: `stdpath("log")/cint-live.log`
    Append daemon output to this file. `false` inherits the daemon's streams.

`debounce_ms`     (number)  default: 150
    Delay before sending a changed buffer to the daemon.

`expand_on_cursor` (boolean) default: true
    Reveal the concealed block under the cursor, including annotations contained
    in it, even when the block itself resolves to SHOW.

`hover`           (table)   default: { enabled = true, on_cursor_hold = true }
    `enabled` controls the intent hover command and trigger. `on_cursor_hold`
    adds the automatic CursorHold/CursorHoldI trigger. The plugin does not
    change `updatetime`. `:CintHover` and <Plug>(CintHover) still work when the
    automatic trigger is off; `enabled = false` disables both.

`handlers`        (table)   default: { "color" }
    Default handlers applied to meanings without a rule entry.

`resolve`         (table)   default: precedence + default
    Merge an annotation's intent meanings into one effective meaning. The first
    meaning present in `precedence` wins; `default` covers empty or unknown
    intent sets.

`rules`           (table)   default: CONCEAL/HIGHLIGHT/IGNORE rules
    Per-meaning rendering rule; see |cint-handlers|.
    `SHOW` defaults to false (no rendering) because it only means "do not
    conceal"; use `HIGHLIGHT` for a background.

`tags`            (table)   default: LOGGING/ERROR_HANDLING/BOOKKEEPING/VALIDATION/UNTAGGED
    Per-intent `meaning`, colors, and priority. `tags[tag].meaning` is the
    client-side semantic label; `rules[meaning]` decides how it renders.

`profile`         (string)  default: "base"
    Initial global profile.

`profiles`        (table)   default: {}
    Named presentation overrides merged over the base config; see
    |cint-profiles|.

`shards`          (table)   default: {}
    Named one-shot overrides applied on top of a profile.

`keymaps`         (table)   default: {}
    Optional `pick`, `edit`, and `shard` normal-mode mappings.

5. HANDLERS                                        *cint-handlers*

How an annotation renders is decided by its client-resolved meaning. The entry
maps a handler name to its options; the presence of a handler enables it. >

  require("cint").setup({
    rules = {
      CONCEAL = { conceal = { lines = true } },
      SHOW = { highlight = true },
      IGNORE = { ignore = { fg = "#555555" } },
    },
    tags = {
      LOGGING = { bg = "#1f2d1f", priority = 10 },
      ERROR_HANDLING = { bg = "#2d1f1f", priority = 50 },
    },
  })
<

Handlers: >
  highlight background color from the chosen tag. opts: bg, color.
  ignore    dark-gray foreground. opts: fg, color.
  color     background tint + gutter sign. opts: bg, sign, icon.
  conceal   replace text with a char, or hide whole lines.
            opts: char (inline), lines (vertical).
<

The highlight color is taken from the highest-priority tag in the span's
`intents` (`tags[tag].priority`), falling back to the renderer's neutral
`colors.fallback` color.

A meaning without a rule entry falls back to the top-level `handlers` list. A
handler may be set to `true` for defaults or `false` to disable it.

`conceal.lines = true` hides the span's lines entirely (no height), leaving the
next visible line; `char` alone replaces the span's text inline. `conceal` sets
the window's `conceallevel` to 2 when it is 0, and can be combined with `color`.

6. PROFILES                                      *cint-profiles*

A profile is a named partial override of the presentation config. `extends`
chains profiles; `false` disables a rule, `nil` inherits. >

  profiles = {
    base = {
      tags = {
        LOGGING = { meaning = "CONCEAL" },
        ERROR_HANDLING = { meaning = "SHOW" },
      },
    },
    review = {
      extends = "base",
      tags = { LOGGING = { meaning = "IGNORE" } },
    },
  }
<

Project profiles live in <project>/.cint/profiles.lua. With `scope =
"global"`, profiles live in `stdpath("config")/cint/profiles.lua`
instead and project files are ignored: >

  return {
    default = "review",
    profiles = {
      review = {
        extends = "base",
        tags = { LOGGING = { meaning = "IGNORE" } },
      },
    },
  }
<

Switching profiles only re-renders; it never re-runs the analysis engine.

Commands: |:CintProfile|, |:CintProfileEdit|,
|:CintProfileReload|. Optional <Plug> mappings:
<Plug>(CintProfilePick) and <Plug>(CintProfileEdit).

7. API                                                *cint-api*

require("cint").setup(opts)   Merge configuration.
require("cint").render()      Render current buffer; returns
                                               the span count.
require("cint").clear()       Clear current buffer.
require("cint").toggle()      Toggle current buffer.
require("cint").refresh()     Reconnect and re-analyze.
require("cint").reveal_block() Expand the concealed block
                                               under the cursor, if any.
require("cint").annotations_at([buf], [line])
                                               Covering published annotations.
                                               `line` is 0-based; when omitted it
                                               comes from a window showing `buf`.
require("cint").provenance_at([buf], [line])
                                               Per-contributor provenance chain
                                               for the annotations at a line.
require("cint").annotations_at_position([buf], [line], [col])
                                               Covering published annotations at
                                               a zero-based line and column;
                                               defaults come from a window
                                               showing `buf`.
require("cint").intents_at_position([buf], [line], [col])
                                               Distinct intents of the
                                               innermost published span at a
                                               zero-based line and column, in
                                               annotation order; UNTAGGED is
                                               omitted and UNTAGGED-only spans
                                               are skipped. Intents are combined
                                               only when span bounds coincide;
                                               the earliest annotation
                                               wins when minimum-size spans are
                                               not coincident.
require("cint").provenance_at_position([buf], [line], [col])
                                               Per-contributor provenance chain
                                               at a zero-based line and column.
require("cint").hover([buf])   Open the intent hover at the cursor or `buf`'s
                                               first current-tab window; false
                                               when there is no such window,
                                               nothing to show, or hover is
                                               disabled.
require("cint").hover_close()  Close the hover if it is open.
require("cint").hover_active() Whether the hover window is open.
require("cint").profile()     Active profile name.
require("cint").set_profile(name, opts)
                                               Set buffer or global profile.
require("cint").pick_profile() Pick a profile.
require("cint").edit_profiles([name])
                                               Edit profiles.
